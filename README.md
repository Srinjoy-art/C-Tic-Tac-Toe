# Tic-Tac-Toe in C

A simple two-player Tic-Tac-Toe game made using C.

I built this project to practise my C programming skills and try something more interactive than regular practice programs. It runs in the terminal, where two players take turns marking the board until someone wins or the game ends in a draw.

## Features

- Two-player gameplay
- 3 × 3 game board
- Turn-based moves using X and O
- Automatic winner detection
- Draw detection
- Option to play another round

## Built With

- C Programming Language
- Standard C Library

## How to Run

Make sure you have a C compiler such as GCC installed.

**Compile the program:**

```bash
gcc Tic_Tac_Toe.c -o tic-tac-toe
```

**Run on Windows:**

```bash
.\tic-tac-toe.exe
```

**Run on Linux or macOS:**

```bash
./tic-tac-toe
```

Replace `Tic_Tac_Toe.c` with the actual name of your source file if it is different.
